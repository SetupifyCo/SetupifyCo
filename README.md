## ⚡ Setupify

Setupify is a Discord utility bot designed to make server setup fast and simple.

Instead of manually creating channels, roles, permissions, and categories, Setupify automatically builds and organizes your server while still allowing full customization.

### Features

- Information channels
- Community channels
- Voice channels
- Staff channels
- Permission roles
- Member and bot autoroles
